# Unsupervised ML on General-Purpose Data: Comparing Clustering Algorithms

**Bootcamp Week 4 · Types of ML Models**

## Overview

A deeper comparison than notebook 12: chooses k with both the elbow method and silhouette score, fits K-Means against known species groups, then benchmarks K-Means, Hierarchical Clustering, and DBSCAN against each other with a dendrogram.

## Dataset

Iris

## What this notebook demonstrates

- Elbow method and silhouette score for choosing k
- K-Means validated against true labels
- Side-by-side comparison of K-Means, Hierarchical Clustering, and DBSCAN
- Dendrogram visualization

## Libraries

`scikit-learn`, `pandas`, `matplotlib`, `scipy`

## Why this project is here

Shows the judgment step every clustering project needs: not just running an algorithm, but comparing several and justifying the choice.

- `notebook.ipynb` — the full, run notebook (cell outputs, including charts, are saved inline and render directly on GitHub)
